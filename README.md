# DETAILING — сайт выездного детейлинга

Статический сайт: один HTML-файл, CSS и JS без сборки, зависимостей и CDN.
Открывается двойным кликом по `index.html` или с любого хостинга (GitHub Pages,
Netlify, Vercel, обычный shared-хостинг).

```
index.html          разметка и весь контент
assets/styles.css   дизайн-токены и стили
assets/app.js       меню, фильтр услуг, смета, валидация формы
assets/favicon.svg  иконка
preview/            скриншоты страницы (десктоп и телефон)
Исходники/          исходный прайс-лист (картинка)
```

## Что заменить перед публикацией

Все данные — демонстрационные. Телефон `+7 999 123-45-67` встречается в `index.html`
шесть раз и в `assets/app.js` (ссылка WhatsApp). Найдите и замените:

| Что | Где |
| --- | --- |
| Телефон | `index.html` — поиск `79991234567` и `+7 999 123-45-67` |
| WhatsApp | `index.html` — `https://wa.me/79991234567`; `assets/app.js` — в обработчике формы |
| Telegram | `index.html` — `https://t.me/detailing_msk` |
| Зона выезда | `index.html` — блок «Контакты» и FAQ «Куда выезжаете?» |
| Условия (зима, гарантия, оплата) | `index.html` — секция `#faq`; это ваши правила, проверьте формулировки |
| Юридические данные | `index.html` — подвал (`© DETAILING`, оферта) |

## Цены

Каждая услуга — это `<label class="svc">` с атрибутами:

```html
data-id="wash"                          идентификатор (для формы и сметы)
data-name="Детейлинг-мойка кузова"      как услуга попадёт в заявку
data-price="3000"                       число, участвует в смете
data-from="1"                           показывать «от» (цена минимальная)
data-group="body"                       категория для фильтра
```

Если меняете цену — поправьте **и** `data-price`, **и** видимый текст
(`3&nbsp;000 ₽`), иначе смета разойдётся с прайсом.
Категории: `body`, `protect`, `salon`, `glass`, `engine`, `complex`.

## Форма

Бэкенда нет: после проверки полей заявка собирается в текст, и посетитель
отправляет её сам — кнопка открывает WhatsApp с уже заполненным сообщением.
Чтобы принимать заявки на почту/в CRM, замените обработчик `submit`
в `assets/app.js` на `fetch()` к Formspree, Telegram-боту или вашему API —
данные уже собраны в объект `data` и массив `services`.

## Дизайн

Токены в начале `assets/styles.css`: цвета, радиусы, кривые анимации
(`--ease-out: cubic-bezier(.23, 1, .32, 1)`), шрифт — системный стек
(`system-ui`), поэтому сайт не тянет веб-шрифты и грузится мгновенно.

Учтено: `prefers-reduced-motion`, `prefers-reduced-transparency`,
`prefers-contrast`, safe-area на iPhone, `100svh` для первого экрана,
поля ≥16px (иначе iOS зумит страницу), `touch-action: manipulation`
(нет задержки тапа), hover-эффекты только на устройствах с мышью.

## Локальный просмотр

Любой статический сервер, например:

```
npx serve .
# или
python -m http.server 8000
```

`file://` тоже работает, но лучше через сервер — так же, как на хостинге.
