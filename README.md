# PENA DETAIL — выездной детейлинг

Статический сайт: HTML + CSS + JS, без сборки, зависимостей и CDN.
Главная идея: **сайт «отмывается» по мере заполнения заявки** — фоновая машина и слой
«грязного стекла» очищаются на каждом шаге, после отправки проходит блик.

```
index.html          главная страница
privacy.html        политика обработки данных
404.html            страница ошибки
assets/config.js    ⚙️ ВСЁ, что нужно заполнить: контакты, реквизиты, цены, интеграции
assets/app.js       логика: темы, очистка, классы цен, шаги заявки, отправка
assets/styles.css   дизайн-токены, две темы, машина, «грязь»
assets/favicon.svg  иконка PD
robots.txt, sitemap.xml
preview/            скриншоты
Исходники/          исходный прайс-лист
```

## Что заполнить перед запуском

Всё в одном файле — `assets/config.js`. Пустое значение = элемент аккуратно скрыт,
вёрстка не ломается.

| Поле | Что это |
| --- | --- |
| `phone`, `phoneDisplay` | телефон: `+79991234567` и как показывать `+7 999 123-45-67` |
| `telegram`, `whatsapp`, `email` | ссылки на мессенджеры и почту |
| `hours` | «Ежедневно, 9:00–21:00» |
| `legal.*` | ИП: ФИО, ИНН, ОГРНИП, адрес — попадут в подвал и в политику |
| `leadEndpoint` / `bitrixWebhook` | куда уходят заявки (см. ниже) |
| `metrikaId` | номер счётчика Яндекс.Метрики |
| `multipliers` | наценка за класс: сейчас 1 / 1.15 / 1.3 |
| `photos` | фотографии работ — включает секцию «Работы» |

## Заявки → Битрикс24

Порядок приоритета в коде: `leadEndpoint` → `bitrixWebhook` → WhatsApp → кнопка
«Скопировать заявку».

**Как получить вебхук:** Битрикс24 → *Разработчикам* → *Другое* → *Входящий вебхук* →
права **crm** → сохранить → скопировать URL вида
`https://xxx.bitrix24.ru/rest/1/abcd1234/`. Вставьте в `bitrixWebhook`.

⚠️ **Важно.** URL вебхука = полный доступ к вашему CRM. Он будет виден в исходниках
сайта любому, кто откроет DevTools, и через него можно спамить лидами. Поэтому:

- **Рекомендуется прокси.** Cloudflare Worker (бесплатно), 20 строк:

```js
export default {
  async fetch(req, env) {
    if (req.method !== 'POST') return new Response('no', { status: 405 });
    const d = await req.json();
    const r = await fetch(env.BITRIX + 'crm.lead.add.json', {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({
        fields: {
          TITLE: 'Сайт: ' + d.klassName + ' ' + (d.car || ''),
          NAME: d.name, PHONE: [{ VALUE: d.phone, VALUE_TYPE: 'WORK' }],
          ADDRESS: d.address, COMMENTS: d.services.join(', '),
          SOURCE_ID: 'WEB'
        }
      })
    });
    return new Response(await r.text(), { headers: { 'access-control-allow-origin': '*' } });
  }
};
```

URL воркера положите в `leadEndpoint`, а вебхук — в секрет воркера (`env.BITRIX`).
Тогда в коде сайта нет ничего секретного.

- Альтернатива без кода — **CRM-форма Битрикс24** (Контент → CRM-формы) и вставка её
  скрипта вместо формы заявки.

Пока ничего не заполнено, форма работает как черновик: заявка собирается в текст,
кнопка копирует её в буфер.

## Эффект «отмывания»

- `data-clean` на `<html>`: 0 (грязно) → 4 (чисто). Меняется на шагах заявки и при отправке.
- Уровни прозрачности — в `styles.css`, блок «Уровни чистоты».
- `dirtEnabled: false` — полностью выключить эффект.
- `dirtReturnDays: 7` — через сколько дней пыль вернётся к тому, кто уже оставлял заявку (0 — никогда).
- При `prefers-reduced-motion` блик и капли отключаются, остаётся кроссфейд.
- На экранах уже 860 px машина скрывается, чтобы не мешать тексту.

## Цены

Базовые цены — в `data-price` у карточек услуг (седан). Класс авто применяет множитель
из `multipliers` и округляет до `roundTo`. Итог пересчитывается в прайсе, в смете и в заявке.

## Галерея работ

Добавьте фотографии в `assets/works/` и заполните:

```js
photos: [
  { src: 'assets/works/1.jpg', title: 'Полировка кузова', car: 'BMW 5', group: 'body' },
]
```

Секция «Работы» появится сама. Пока массив пуст — она скрыта.

## Домен penadetail.ru

1. Купите домен (reg.ru, timeweb, nic.ru — любой).
2. В DNS пропишите **A** для `@`: `185.199.108.153`, `185.199.109.153`,
   `185.199.110.153`, `185.199.111.153`
   и **AAAA**: `2606:50c0:8000::153`, `2606:50c0:8001::153`,
   `2606:50c0:8002::153`, `2606:50c0:8003::153`.
3. **CNAME** для `www` → `melonushka.github.io`.
4. В репозитории создайте файл `CNAME` с одной строкой `penadetail.ru`.
5. GitHub → Settings → Pages → Custom domain → `penadetail.ru` → Enforce HTTPS.
6. В `index.html` замените `https://penadetail.ru` в `sitemap.xml` и `robots.txt`,
   если домен будет другой.
